# 🧮 Calculator

A simple and interactive **Calculator** built using **HTML, CSS, and JavaScript**.

The calculator provides a clean interface for performing basic mathematical calculations directly in the browser.

## 🌐 Live Demo

👉 **[Visit Calculator](https://aryanh12345.github.io/Calculator/)**

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Numeric input
- 🧹 Clear functionality
- ⚡ Instant calculations
- 🎨 Clean and simple interface
- 📱 Responsive design
- 💻 Works directly in the browser

## 🛠️ Technologies Used

- **HTML5** – Calculator structure
- **CSS3** – Styling and layout
- **JavaScript** – Calculator logic and interactions
